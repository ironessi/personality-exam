# SOURCES —— common（通用层）语料来源与许可

> 本目录语料用于心理测评报告的检索增强生成（RAG），会被切块后写入本地向量库。
> 本文件是 §7.1「每份入库文档须在 `data/raw/<namespace>/SOURCES.md` 记录来源与许可」的落地。
> `common` 是**通用层**（ADR-0008），不是测评名：**全部 42 个测评**的检索范围都包含它（策略为 `common_only` 的两个测评**只**检索它，策略为 `disabled` 的两个不检索任何语料）。因此本目录是**全平台唯一被普遍共享的知识层**，改动它的影响面最大。
> 本文件自身被 `app/ingest/loader.py` 的 `SKIP_NAMES` 跳过，不会被切块入库。

## 三、使用方式声明（重要）

本目录全部语料均为**项目自撰**（原创中文表述），不派生自任何外部文档，因此不需要上游授权。具体而言：

- **不是**上述任何来源的译本、节选、扫描件或逐段转述；
- **不含**任何来源的整段原文，也不含其结构化复制；
- 测量学概念（信度、效度、常模）、治疗取向介绍、情绪调节技巧均为公共知识层面的通用科普，具体表述、例子、判断标准、章节组织均为本项目中新写。

因此验收项「无整段版权原文」是由**产出方式**保证的，而不是靠事后抽查。

> ⚠️ **「改写」不是安全港**：对 NC / ND / 全版权来源做改写，产出的仍是**演绎作品**，NC 与 SA 条款会随演绎作品传递。本目录**没有**以 OpenStax《Psychology 2e》、NOBA（均为 CC BY-NC-SA 4.0）或 WHO ICD-11（ND）为改写依据，正文一字未取自它们。

## 四、本目录独有的风险：可核实的硬事实

「专业心理求助渠道.md」必然涉及**具体机构、热线号码、就诊流程**这类可核实的硬事实。这类内容最容易在自行撰写中被编造，而读者一旦照做会付出真实代价。因此本目录额外遵守：

1. 正文中**不出现具体电话号码与网址**，只描述「如何找到本地资源」的方法（如通过医院官网、当地卫生健康委员会公示信息、单位 EAP 项目等）；
2. 不出现具体的医院、机构、咨询师姓名，也不声称与其存在合作或推荐关系；
3. 涉及费用、疗程、医保的表述一律加「各地差异较大，以就诊机构公示为准」；
4. 需要列举求助入口时，只列举**类别**（精神科门诊、心理援助热线、高校心理咨询中心、员工帮助计划），不列举具体号码。

这条限制是刻意的：语料是给检索增强用的，读者会把它当作可执行的行动指南。**宁可让回答提示「去查当地官方公示」，也不要给出一个可能已经失效或根本是编造的号码。**

⚠️ 本目录是**全平台共享层**，因此它的任何偏差会被 42 个测评继承。改动本目录后必须重跑全部域的检索评测，不能只抽查本域。

## 五、明确未使用的来源

| 来源 | 原因 |
|---|---|
| DSM-5 / APA 正文与诊断标准 | 全版权保留，禁止入库 |
| 各量表官方手册 | 商标 + 版权，禁止入库 |
| OpenStax《Psychology 2e》 | **实为 CC BY-NC-SA 4.0**（不是 CC BY 4.0）：NC 与付费产品冲突，SA 要求演绎作品同许可开源，故不作改写依据 |
| NOBA Project | CC BY-NC-SA 4.0 含 NC 条款，本项目不采用 |
| 任何商业咨询机构的营销页面、课程文案 | 版权 + 利益冲突 |
| 各心理援助热线的号码与机构名单 | 时效性不可控 + 无法核实，按第四节规则一律不写入正文 |
