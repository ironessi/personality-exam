# SOURCES —— typology（类型学人格）语料来源与许可

> 本目录语料用于心理测评报告的检索增强生成（RAG），会被切块后写入本地向量库。
> 本文件是 §7.1「每份入库文档须在 `data/raw/<namespace>/SOURCES.md` 记录来源与许可」的落地。

本目录全部语料均为**项目自撰**（原创中文表述），不派生自任何外部文档，因此不需要上游授权。具体而言：

- **不是**上述任何来源的译本、节选、扫描件或逐段转述；
- **不含**任何来源的整段原文，也不含其结构化复制；
- 概念框架（如四组维度、八种认知功能、任务/关系两轴）取自公有领域著作，属于思想与体系层面，不受著作权保护；
- 具体表述、例子、判断标准、章节组织均为本项目中新写。

因此验收项「无整段版权原文」是由**产出方式**保证的，而不是靠事后抽查。

> ⚠️ **「改写」不是安全港**：对 NC / ND / 全版权来源做改写，产出的仍是**演绎作品**，NC 与 SA 条款会随演绎作品传递。所以本目录**没有**以 OpenStax、NOBA（NC-SA）或 WHO ICD-11（ND）为改写依据——它们只可能作为「概念从哪里来」的旁证，正文一字未取自它们。

## 五、商标与限制声明

`MBTI®` 是 The Myers-Briggs Company 的注册商标，`Everything DiSC®` 是 Wiley 的注册商标。本目录语料在正文中一律使用**通用术语**：「16 型人格」「荣格八维」「认知功能」，以及 `INTJ` / `ENFJ` 这类字母码；DISC 部分只使用 `D` / `I` / `S` / `C` 与中文的中性描述词（支配 / 影响 / 稳健 / 谨慎）。

**禁止**在语料、产品文案与检索 query 中出现「建筑师」「逻辑学家」「主人公」「调停者」「指挥官」「辩论家」「竞选者」「守卫者」「探险家」「艺术家」等 16Personalities 自创别称。

**DISC 不是人格理论，也不是能力或道德评价。** 它是一种描述**可观察行为倾向**的观察框架。DISC 相关语料在正文中一致遵守以下边界：

- 不用于招聘筛选、晋升淘汰或任何人事决策；
- 不把某一风格说成更优或更差；
- 不把测评结果当作对人的固定结论，强调同一风格内部差异极大、行为会随情境调整；
- 不使用「支配型人格」「影响型人格」这类把行为倾向说成人格类型的措辞。
